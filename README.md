## GRPC Train Booking Application

This is a simple gRPC-based train booking system that allows users to purchase train tickets, modify their seat allocation, and retrieve ticket information. The system provides multiple functionalities like:
- Purchasing a ticket for a user
- Retrieving a user's ticket receipt
- Listing users by section
- Removing users from the system
- Modifying a user's seat

## Features
- **Purchase Ticket**: Allows users to book a ticket, allocating a seat and section.
- **Get Receipt**: Fetches the ticket receipt of a user based on their email.
- **Get Users by Section**: Lists all users allocated to a specific section of the train.
- **Remove User**: Removes a user from the system based on their email.
- **Modify Seat**: Allows modifying the seat and section assigned to a user.
